Demo built with Divine Voxel Engine.

## Features
- infinite world generation
- biome based world generation
- player physics
- lots of voxels to place
- breaking voxels creates particles

## Controls 
- **WASD** move
- **mouse** look
- **Space** jump, swim up
- **wheel** change item selected in main inventory
- **primary click** use main hand 
- **secondary click** use off hand, delete item from inventory
- **E** open inventory
- **F** switch item from main hand to off hand.

## Run Locally
```console
git clone https://github.com/Divine-Star-Software/DivineCraft.git
git lfs pull
npm install
npm run start
```
